# OpenTestAI

OpenTestAI is a TypeScript service for generating automated test cases with an Ollama-backed language model.

## Project structure

```text
src/
├── config/
├── llm/
├── agents/
├── routes/
├── services/
└── utils/
```

## Setup

Install dependencies:

```bash
npm install
```

Copy the required environment values into `.env` before running the service.

## Development

Type-check the project with:

```bash
npx tsc --noEmit
```
